# 📊 (Data-to-Chart)

Sebuah aplikasi web ringan dan pantas untuk menukar data mentah kepada visualisasi graf yang cantik. Dibina khas untuk pengguna biasa dan *developer* yang memerlukan graf pantas tanpa perlu menetapkan konfigurasi yang rumit.

## ✨ Ciri-Ciri Utama

* **Sokongan Multi-Dataset:** Bandingkan berbilang set data dalam satu graf dengan mudah.
* **Import Fail Pintar:** Muat naik fail `.xlsx`, `.xls`, atau `.csv` dan petakan (map) lajur paksi-X dan paksi-Y mengikut kehendak anda.
* **Pelbagai Jenis Graf:** Menyokong graf Bar, Line, Area, Mixed (Bar+Line), Pie, Doughnut, dan banyak lagi.
* **Tema Warna Dinamik:** Pilih satu warna korporat dan sistem akan menjana tona warna (opacity) secara automatik.
* **Eksport Pantas:** 
  * Muat turun graf sebagai imej `.PNG`.
  * Salin *HTML Snippet* (Menyokong Data Statik & Mod Dev dengan pembolehubah asing).

## 🛠️ Teknologi Yang Digunakan

* **Frontend Framework:** Vue 3 + Vite
* **Penyusun Gaya (Styling):** Tailwind CSS v4
* **Enjin Graf:** Chart.js
* **Pemprosesan Data:** SheetJS (xlsx)
