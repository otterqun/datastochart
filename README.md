## 📊 Data-to-Chart

A lightweight and fast web application for transforming raw data into beautiful data visualizations. Designed for both everyday users and **developers** who need to create charts quickly without dealing with complicated configurations ..

## ✨ Key Features

* **Multi-Dataset Support:** Easily compare multiple datasets within a single chart.

* **Smart File Import:** Upload `.xlsx`, `.xls`, or `.csv` files and map the X-axis and Y-axis columns according to your requirements.

* **Multiple Chart Types:** Supports Bar, Line, Area, Mixed (Bar + Line), Pie, Doughnut, and more.

* **Dynamic Color Themes:** Select a single corporate color, and the system automatically generates different color tones and opacity levels.

* **Quick Export:**

  * Download charts as `.PNG` images.
  * Copy **HTML Snippets** with support for both static data and **Developer Mode** using external variables.

## 🛠️ Technologies Used

* **Frontend Framework:** Vue 3 + Vite
* **Styling:** Tailwind CSS v4
* **Charting Engine:** Chart.js
* **Data Processing:** SheetJS (xlsx)
